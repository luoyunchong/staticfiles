# Getting started

## Project overview

> An introduction to the project's base libraries, with documentation to help developers get started.

> how to run ?  [Documentation](https://docsify.js.org/#/zh-cn/quickstart)

- Open the project in VS Code and enter the following commands in the terminal.

* Install docsify-cli
```
    npm i docsify-cli -g
```
From the docs directory, run:
```bash
    docsify serve .
```
Or run this from the parent directory of docs:
```
 docsify serve docs
```

Finally, open  [http://localhost:3000](http://localhost:3000)
